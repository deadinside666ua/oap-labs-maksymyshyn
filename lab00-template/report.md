# ЛРNN. Назва лабораторної роботи

| | |
|---|---|
| **Студент** | Прізвище Ім'я, КІ-21 |
| **Варіант** | N |
| **Дата виконання** | РРРР-ММ-ДД |
| **Середовище** | Visual Studio 2022 (MSVC 19.4x) / VS Code + g++ 14.x |

> Обов'язковий мінімум для груп КІ: розділи 2, 5, 6 для кожного завдання і розділ 3 для завдання
> за варіантом. Групи ПЗ заповнюють усі розділи для кожного завдання. Зайве — видаліть.

## 1. Мета роботи

Одне-два речення своїми словами: чого треба навчитися в цій роботі.

## 2. Постановка задачі

Умова завдання за варіантом, переписана у формі:

- **Вхід:** які дані вводить користувач, їх типи та діапазони.
- **Вихід:** що і в якому форматі виводить програма.
- **Обмеження:** що вважається некоректним входом.
- **Особливі випадки:** межі діапазонів, нуль, від'ємні значення, ділення на нуль тощо.

## 3. Алгоритм

Псевдокод (за домовленостями лекції 2) або блок-схема (рисунок `flowchart.png`, зроблений у diagrams.net).
Групи КІ: лише для завдання за варіантом (у листку завдання сказано, для якого); групи ПЗ — для кожного завдання.

```text
ВВЕСТИ ...
ЯКЩО ... ТО
    ...
КІНЕЦЬ ЯКЩО
ВИВЕСТИ ...
```

## 4. Програма

Файл [`main.cpp`](main.cpp). Тут — лише те, що варто пояснити: які змінні і навіщо,
які функції бібліотеки використано, чому обрано саме такий спосіб.

|:--|:--|:--|:--|:--|
| 1 | | | | типовий випадок |
| 2 | | | | межа діапазону |

Для завдань на розгалуження — по одному тесту на кожну гілку.
